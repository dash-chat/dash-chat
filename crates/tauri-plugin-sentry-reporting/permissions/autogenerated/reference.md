## Default Permission

Allows submitting error reports to Sentry.

#### This default permission set includes the following:

- `allow-send-error-report`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`sentry-reporting:allow-send-error-report`

</td>
<td>

Enables the send_error_report command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`sentry-reporting:deny-send-error-report`

</td>
<td>

Denies the send_error_report command without any pre-configured scope.

</td>
</tr>
</table>
